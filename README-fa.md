## DualNet چیست

ویندوز وقتی به دو اینترنت وصل باشد، معمولاً فقط از یکی استفاده می‌کند. DualNet یک پراکسی کوچک روی کامپیوتر خودتان است که هر اتصال جدید را از یکی از اینترنت‌ها می‌فرستد. نتیجه:

- **سرعت بیشتر:** در دانلودهای چنداتصاله (IDM، تورنت، چند دانلود همزمان) سرعت کل نزدیک به جمع سرعت دو اینترنت می‌شود.
- **پشتیبان خودکار:** اگر یکی از اینترنت‌ها قطع شود، اتصال‌های بعدی خودکار از دیگری می‌روند.
- **صرفه‌جویی:** می‌توانید بگویید اینترنت ارزان اول استفاده شود و اینترنت گران‌تر (مثلاً 5G) فقط وقتی اولی پر است.

نمونه‌ی اندازه‌گیری‌شده:

| حالت | سرعت |
|---|---|
| فقط LAN (ADSL) | ۱۵٫۱ مگابیت |
| فقط Wi-Fi (هات‌اسپات 5G گوشی) | ۴۵٫۹ مگابیت |
| **هر دو با DualNet** | **۶۰٫۵ مگابیت** |

## پیش‌نیازها

- ویندوز ۱۰ یا ۱۱ (روی ویندوز ۷ هم کار می‌کند، به شرطی که .NET Framework 4.5 یا جدیدتر نصب باشد).
- دو اینترنت از **دو منبع جدا**، مثلاً یک مودم ADSL با کابل LAN و یک مودم یا گوشی دیگر با Wi-Fi. اگر LAN و Wi-Fi هر دو به یک مودم وصل باشند، سرعت جمع نمی‌شود.
- نصب لازم نیست و دسترسی ادمین هم نمی‌خواهد.

## دانلود و اجرا

1. به صفحه‌ی [Releases](../../releases) بروید و فایل `DualNet-v1.0.0.zip` (یا نسخه‌ی جدیدتر) را دانلود کنید.
2. فایل zip را در یک پوشه باز کنید (Extract). نه از داخل خود zip اجرا کنید.
3. کابل LAN را وصل کنید و به Wi-Fi دوم هم وصل شوید.
4. روی `start.bat` دوبار کلیک کنید.
   - اگر ویندوز هشدار «Windows protected your PC» داد، روی **More info** و بعد **Run anyway** بزنید. این هشدار برای این است که فایل امضای دیجیتال ندارد.
   - یک پنجره‌ی سیاه باز می‌شود و اینترنت‌های پیداشده را نشان می‌دهد. این پنجره را باز نگه دارید.
   - داشبورد در مرورگر باز می‌شود: `http://127.0.0.1:1080/`
   - پراکسی ویندوز خودکار روشن می‌شود، پس Chrome، Edge و IDM بدون تنظیم اضافه از DualNet استفاده می‌کنند.
5. برای خاموش کردن، پنجره‌ی سیاه را ببندید یا در آن `Ctrl+C` بزنید. پراکسی ویندوز خودکار به حالت قبل برمی‌گردد.

| فایل | کار |
|---|---|
| `start.bat` | اجرا و روشن کردن پراکسی ویندوز (برای بیشتر کاربران) |
| `start-proxy-only.bat` | اجرا بدون تغییر تنظیمات ویندوز (برای استفاده همراه VPN، یا وقتی می‌خواهید پراکسی را فقط در بعضی برنامه‌ها بگذارید) |
| `fix-internet.bat` | خاموش کردن پراکسی ویندوز اگر DualNet به‌زور بسته شد و سایت‌ها باز نمی‌شوند |
| `build.bat` | ساخت دوباره‌ی `DualNet.exe` از روی سورس |

## داشبورد

آدرس داشبورد `http://127.0.0.1:1080/` است و هر ثانیه به‌روز می‌شود:

- **بالای صفحه:** سرعت دانلود و آپلود کل، تعداد اتصال‌های باز، و تعداد اینترنت‌های فعال.
- **نوار رنگی:** سهم هر اینترنت از دانلود همان لحظه.
- **کارت هر اینترنت:** وضعیت (آنلاین، بدون اینترنت یا قطع)، پینگ، سرعت دانلود و آپلود، اتصال‌های باز، مجموع دانلود، نمودار سرعت ۶۰ ثانیه‌ی اخیر، و مصرف این ماه.
- **دکمه‌های هر کارت:**
  - «اولویت با این» یا «برداشتن اولویت» (توضیح در بخش بعد).
  - «سرعت خط»: سرعت این اینترنت را به مگابیت وارد کنید.
  - «خاموش کن» یا «روشن کن»: این اینترنت موقتاً استفاده نشود. برای تست سرعت هر اینترنت به‌تنهایی مفید است.

## اولویت: کدام اینترنت اول استفاده شود

دو حالت دارید که بالای داشبورد بین‌شان جابه‌جا می‌شوید:

- **اولویت‌دار (ارزان):** همه چیز اول از اینترنتی می‌رود که اولویت دارد. فقط وقتی آن پر شود (به ۸۰٪ سرعتش برسد) یا قطع شود، اتصال‌های جدید به اینترنت دوم می‌روند. برای وقتی که یک خط ارزان دارید (مثلاً ADSL) و یک خط گران (مثلاً 5G حجمی).
- **همه با هم (سریع):** اتصال‌ها همیشه بین همه‌ی اینترنت‌ها پخش می‌شوند. بیشترین سرعت را می‌دهد، ولی از هر دو اینترنت مصرف می‌کند.

**تنظیم اولویت:**

1. روی کارت اینترنت ارزان‌تر «اولویت با این» را بزنید.
2. روی همان کارت «سرعت خط» را بزنید و سرعت واقعی‌اش را به مگابیت وارد کنید، مثلاً `16` برای ADSL شانزده مگابیتی. اگر خالی بگذارید، برنامه از بیشترین سرعتی که دیده خودش یاد می‌گیرد.

انتخاب‌ها در فایل `settings-<اسم کامپیوتر>.txt` کنار برنامه ذخیره می‌شوند و بعد از بستن و باز کردن برنامه می‌مانند. هر کامپیوتر فایل خودش را دارد، پس می‌شود پوشه‌ی برنامه را در Dropbox یا فلش گذاشت و روی چند کامپیوتر استفاده کرد. روی هر کامپیوتر یا شبکه‌ی جدید، فقط یک بار در داشبورد اولویت را انتخاب کنید.

> اتصالی که باز شده وسط کار از یک اینترنت به دیگری نمی‌رود. فقط اتصال‌های جدید جابه‌جا می‌شوند. IDM مدام اتصال جدید باز می‌کند، پس از هر دو اینترنت استفاده می‌کند.

## سقف مصرف

برای اینکه از یک اینترنت حجمی بیشتر از مقدار مشخص مصرف نشود، `start.bat` را با Notepad باز کنید و آخر خطی که با `DualNet.exe` شروع می‌شود این را اضافه کنید:

```
--limit Wi-Fi=10GB
```

به‌جای `Wi-Fi` اسم کارت شبکه را بنویسید (در داشبورد می‌بینید) و به‌جای `10GB` هر مقداری که خواستید (`MB`، `GB` یا `TB`).

- وقتی مصرف به سقف برسد، اتصال‌های باز آن اینترنت بسته می‌شوند. از آن به بعد، آن اینترنت فقط وقتی استفاده می‌شود که بقیه قطع باشند.
- سقف ماهانه است و اول هر ماه از صفر شروع می‌شود. برای سقف روزانه، `--limit-period day` را هم اضافه کنید.
- مصرف در فایل `usage-<اسم کامپیوتر>.txt` ذخیره می‌شود.
- فقط ترافیکی شمرده می‌شود که از DualNet رد شده. برنامه‌هایی که از پراکسی استفاده نمی‌کنند (مثل Windows Update) از اینترنت اصلی ویندوز می‌روند.

## تنظیم برنامه‌ها

با `start.bat`، مرورگرها و IDM خودکار از DualNet استفاده می‌کنند. برای بقیه‌ی برنامه‌ها، یا اگر با `start-proxy-only.bat` اجرا کرده‌اید، پراکسی را دستی بگذارید:

- **آدرس:** `127.0.0.1`
- **پورت:** `1080`
- **نوع:** SOCKS5 یا HTTP (هر دو روی همین پورت کار می‌کنند).

**IDM:** در Options ← Proxy/Socks گزینه‌ی Use system settings را بزنید (با `start.bat`)، یا HTTP یا SOCKS را دستی روی `127.0.0.1:1080` بگذارید. در Options ← Connection تعداد اتصال (Default max. conn. number) را روی ۸ یا بیشتر بگذارید تا تکه‌های دانلود بین دو اینترنت پخش شوند.

**qBittorrent:** در Tools ← Options ← Connection ← Proxy Server نوع SOCKS5، آدرس `127.0.0.1` و پورت `1080` را بگذارید.

**Firefox:** در Settings ← Network Settings ← Manual proxy configuration گزینه‌ی SOCKS Host را `127.0.0.1` و پورت را `1080` بگذارید، SOCKS v5 را انتخاب کنید و تیک Proxy DNS when using SOCKS v5 را بزنید.

**Chrome و Edge:** از پراکسی ویندوز استفاده می‌کنند و با `start.bat` تنظیم دیگری لازم نیست.

## استفاده همراه VPN (مثل Throne یا v2rayN)

برنامه‌های VPN هم می‌خواهند پراکسی ویندوز را در دست بگیرند، و ویندوز فقط یکی را قبول می‌کند. راه‌حل این است که دو برنامه را پشت سر هم وصل کنید:

**برنامه‌ها ← برنامه‌ی VPN ← DualNet ← دو اینترنت ← سرور VPN**

1. DualNet را با `start-proxy-only.bat` اجرا کنید، نه `start.bat`.
2. در برنامه‌ی VPN یک پروفایل از نوع **SOCKS** بسازید: آدرس `127.0.0.1`، پورت `1080`، نسخه‌ی 5، بدون نام کاربری و رمز.
3. یک پروفایل **Chain** (زنجیره) بسازید: اول پروفایل SOCKS بالا، بعد سرور VPN خودتان. اگر وصل نشد، ترتیب را برعکس امتحان کنید.
4. پروفایل Chain را انتخاب کنید و System Proxy را در برنامه‌ی VPN روشن کنید.

**شرط‌های لازم:**

- **Mux را خاموش کنید.** اگر روشن باشد، همه چیز در یک اتصال جمع می‌شود و فقط از یک اینترنت می‌رود.
- **پروتکل باید روی TCP باشد:** VLESS، VMess یا Trojan با TCP، WS یا Reality. ترنسپورت‌های XHTTP و gRPC هم معمولاً همه چیز را در یک اتصال جمع می‌کنند. Hysteria، TUIC، WireGuard و هر چیزی که روی UDP یا QUIC کار می‌کند از DualNet رد نمی‌شود.
- **محدودیت IP روی سرور:** سرور شما را با دو IP مختلف می‌بیند. اگر روی اکانت‌تان محدودیت «۱ IP» گذاشته شده، ممکن است قطع شوید.
- از حالت TUN برنامه‌ی VPN استفاده نکنید؛ فقط System Proxy.
- سرعت کل هیچ‌وقت از سرعت خود سرور VPN بیشتر نمی‌شود.

## استفاده برای گوشی یا کامپیوترهای دیگر

اگر DualNet را با گزینه‌ی `--lan` اجرا کنید (آخر خط داخل `start.bat` اضافه کنید)، دستگاه‌های دیگر همان شبکه هم می‌توانند از آن استفاده کنند. در آن دستگاه‌ها پراکسی را روی **IP همین کامپیوتر** و پورت `1080` بگذارید. بار اول ویندوز درباره‌ی فایروال سؤال می‌کند که باید Allow بزنید.

بدون `--lan`، برنامه فقط از روی همین کامپیوتر قابل استفاده است.

## چه چیزی سریع‌تر می‌شود و چه چیزی نه

| کار | نتیجه |
|---|---|
| IDM و دانلود منیجرهای چنداتصاله | سرعت کل نزدیک به جمع دو اینترنت |
| تورنت | سرعت کل نزدیک به جمع دو اینترنت |
| چند دانلود یا چند تب همزمان در مرورگر | پخش بین دو اینترنت |
| اسپیدتست در حالت Multi | نزدیک به جمع دو اینترنت |
| یک دانلود تک‌اتصاله، یک ویدیو، تماس تصویری | فقط از یک اینترنت می‌رود |
| بازی‌ها و برنامه‌های UDP | از DualNet رد نمی‌شوند |
| برنامه‌هایی که پراکسی را پشتیبانی نمی‌کنند | از اینترنت اصلی ویندوز می‌روند |

جمع کردن سرعت برای **یک اتصال تکی** فقط با یک سرور واسط در آن طرف ممکن است و DualNet این کار را نمی‌کند.

## عیب‌یابی

**DualNet را بستم و حالا هیچ سایتی باز نمی‌شود.**
احتمالاً برنامه به‌زور بسته شده (مثلاً از Task Manager) و پراکسی ویندوز روشن مانده. `fix-internet.bat` را اجرا کنید، یا در Settings ← Network & internet ← Proxy گزینه‌ی Use a proxy server را خاموش کنید.

**فقط یکی از اینترنت‌ها در داشبورد دیده می‌شود.**
آن یکی یا وصل نیست یا Default Gateway ندارد. مطمئن شوید هر دو اینترنت جداگانه کار می‌کنند. اگر به‌جای یک اینترنت، یک کارت VPN دیده می‌شود، با `--exclude` اسمش را حذف کنید.

**هر دو آنلاین‌اند ولی سرعت جمع نمی‌شود.**
- اگر حالت «اولویت‌دار» روشن است، اینترنت دوم فقط وقتی استفاده می‌شود که اولی پر باشد. برای تست، «همه با هم» را بزنید.
- اسپیدتست را در حالت Multi بگیرید، نه Single.
- در IDM تعداد اتصال را بالا ببرید.
- اگر از VPN رد می‌شوید، بخش [استفاده همراه VPN](#استفاده-همراه-vpn-مثل-throne-یا-v2rayn) را ببینید (Mux و نوع پروتکل).
- با دکمه‌های «خاموش کن» سرعت هر اینترنت را جدا تست کنید. شاید یکی خیلی کند باشد.

**می‌گوید Port 1080 is already in use.**
یک DualNet دیگر از قبل باز است، یا برنامه‌ی دیگری از این پورت استفاده می‌کند. آن را ببندید، یا با `--port 1081` اجرا کنید (و در برنامه‌ها هم پورت را عوض کنید).

**یک اینترنت «بدون اینترنت» نشان داده می‌شود ولی کار می‌کند.**
DualNet سلامت هر اینترنت را با وصل شدن به چند سرور شناخته‌شده (مثل 1.1.1.1 و 8.8.8.8) چک می‌کند. اگر آن‌ها فیلتر باشند، ممکن است وضعیت اشتباه نشان داده شود، ولی تا وقتی ترافیک واقعی رد شود، برنامه از آن اینترنت استفاده می‌کند.

**سایتی مرا از حسابم بیرون می‌اندازد.**
بعضی سایت‌ها (مثل بانک‌ها) اگر IP شما وسط کار عوض شود، شما را بیرون می‌اندازند. با گزینه‌ی `--sticky` اجرا کنید تا هر سایت ۱۰ دقیقه روی یک اینترنت بماند.

**آنتی‌ویروس هشدار می‌دهد.**
فایل exe امضای دیجیتال ندارد و تنظیم پراکسی ویندوز را عوض می‌کند، برای همین بعضی آنتی‌ویروس‌ها حساس می‌شوند. سورس کامل در همین صفحه هست. اگر خیالتان راحت نیست، با `build.bat` خودتان از روی سورس بسازید.

## همه‌ی گزینه‌ها

گزینه‌ها را آخر خطی که در `start.bat` یا `start-proxy-only.bat` با `DualNet.exe` شروع می‌شود اضافه کنید:

| گزینه | کار |
|---|---|
| `--prefer NAME` | مثل دکمه‌ی «اولویت با این» (بر انتخاب داشبورد غلبه می‌کند) |
| `--speed NAME=16` | مثل دکمه‌ی «سرعت خط» (به مگابیت) |
| `--fast` | شروع در حالت «همه با هم» |
| `--limit NAME=10GB` | سقف مصرف |
| `--limit-period day` | سقف روزانه به‌جای ماهانه |
| `--weight NAME=2` | در حالت «همه با هم»، اتصال‌های بیشتری به این اینترنت بدهد (اینجا دو برابر) |
| `--sticky` | هر سایت ۱۰ دقیقه روی یک اینترنت بماند |
| `--exclude NAME` | کارتی که اسمش NAME دارد استفاده نشود (مثلاً کارت VPN) |
| `--only NAME` | فقط از کارت‌هایی با این اسم استفاده شود (قابل تکرار) |
| `--port 1081` | پورت دیگر (پیش‌فرض ۱۰۸۰) |
| `--lan` | دستگاه‌های دیگر شبکه هم بتوانند استفاده کنند |
| `--system-proxy` | روشن کردن پراکسی ویندوز تا وقتی برنامه باز است (در `start.bat` هست) |
| `--clear-proxy` | خاموش کردن پراکسی ویندوز و خروج (همان `fix-internet.bat`) |

`NAME` لازم نیست اسم کامل باشد: `Ethernet` با `Ethernet 2` هم جور می‌شود. اسم کارت‌ها را در داشبورد یا پنجره‌ی سیاه برنامه می‌بینید.

## ساخت از روی سورس

`build.bat` را اجرا کنید. چیزی نصب نمی‌شود، چون از کامپایلر C# داخلی ویندوز (`csc.exe` در .NET Framework 4) استفاده می‌کند. سورس در پوشه‌ی `src` است.
