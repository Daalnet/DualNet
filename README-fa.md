# DualNet — استفاده‌ی همزمان از LAN و Wi-Fi

**دانلود:** فایل `DualNet.exe` را از بخش Releases همین صفحه بگیرید و کنار فایل‌های `.bat` بگذارید، یا `build.bat` را اجرا کنید تا از روی سورس ساخته شود.

DualNet یک پراکسی کوچک روی کامپیوتر خودتان است که اتصال‌ها را بین چند اینترنت پخش می‌کند. وقتی یکی قطع شود، اتصال‌های بعدی خودکار از دیگری می‌روند.

## اولویت: کدام اینترنت اول استفاده شود

در داشبورد (`http://127.0.0.1:1080/`) روی کارت هر اینترنت این دکمه‌ها هست:

- **اولویت با این:** همه چیز اول از این اینترنت می‌رود. فقط وقتی پر شود (۸۰٪ سرعتش) یا قطع شود، اتصال‌های جدید به بقیه می‌روند. برای خط ارزان مناسب است.
- **برداشتن اولویت:** اتصال‌ها بین همه پخش می‌شوند.
- **سرعت خط:** سرعت این اینترنت به مگابیت، مثلاً ۱۶ برای یک ADSL شانزده مگابیتی. برنامه با این عدد می‌فهمد خط کی «پر» است. اگر خالی بگذارید، برنامه خودش از بیشترین سرعتی که دیده یاد می‌گیرد.

بالای داشبورد هم می‌توانید بین «اولویت‌دار (ارزان)» و «همه با هم (سریع)» جابه‌جا شوید.

انتخاب‌ها در فایل `settings-<اسم کامپیوتر>.txt` کنار برنامه ذخیره می‌شوند. بعد از بستن و باز کردن برنامه می‌مانند، و هر کامپیوتر فایل خودش را دارد. پس می‌شود پوشه را در Dropbox گذاشت و روی چند کامپیوتر استفاده کرد. روی یک شبکه یا کامپیوتر جدید، فقط در داشبورد اولویت را انتخاب کنید.

- اتصالی که باز شده وسط کار جابه‌جا نمی‌شود. فقط اتصال‌های جدید به اینترنت دوم می‌روند. IDM اتصال جدید باز می‌کند، پس از هر دو استفاده می‌کند.
- **سقف مصرف:** به خط آخر `start.bat` گزینه‌ی `--limit Wi-Fi=10GB` را اضافه کنید (هر عددی که خواستید). وقتی مصرف ماه به سقف رسید، اتصال‌های باز آن اینترنت بسته می‌شوند و از آن به بعد فقط موقع قطعی بقیه استفاده می‌شود. ماه بعد از صفر شروع می‌شود. مصرف در فایل `usage-<اسم کامپیوتر>.txt` ذخیره می‌شود.
- مصرفی که داشبورد نشان می‌دهد فقط ترافیکی است که از DualNet رد شده. برنامه‌های دیگر ویندوز از اینترنت اصلی ویندوز می‌روند (روی این کامپیوتر Ethernet).

## راه‌اندازی

1. کابل LAN را به مودم اول وصل کنید و Wi-Fi را به مودم دوم.
2. روی `start.bat` دوبار کلیک کنید.
   - پراکسی ویندوز روشن می‌شود، پس مرورگرها (Chrome، Edge) و IDM خودکار از آن استفاده می‌کنند.
   - داشبورد در مرورگر باز می‌شود: `http://127.0.0.1:1080/`
3. برای خاموش کردن، پنجره‌ی سیاه را ببندید یا `Ctrl+C` بزنید. پراکسی ویندوز به حالت قبل برمی‌گردد.

اگر برنامه به‌زور بسته شد (مثلاً از Task Manager) و سایت‌ها باز نشدند، `fix-internet.bat` را اجرا کنید.

## فایل‌ها

| فایل | کار |
|---|---|
| `start.bat` | اجرا و روشن کردن پراکسی ویندوز (پیشنهادی) |
| `start-proxy-only.bat` | اجرا بدون تغییر تنظیمات ویندوز؛ پراکسی را خودتان در هر برنامه تنظیم کنید |
| `fix-internet.bat` | خاموش کردن پراکسی ویندوز اگر چیزی گیر کرد |
| `build.bat` | ساخت دوباره‌ی `DualNet.exe` از سورس (پوشه‌ی `src`) |

## تنظیم دستی در برنامه‌ها

آدرس: `127.0.0.1` پورت: `1080`. نوع SOCKS5 یا HTTP، هر دو روی همین پورت کار می‌کنند.

- **IDM:** Options → Proxy/Socks → Use system settings (با `start.bat` کافی است)، یا HTTP یا SOCKS را دستی روی `127.0.0.1:1080` بگذارید. تعداد Connection را روی ۸ یا بیشتر بگذارید تا تکه‌ها بین دو اینترنت پخش شوند.
- **qBittorrent:** Settings → Connection → Proxy → SOCKS5، آدرس `127.0.0.1` پورت `1080`.
- **Firefox:** Settings → Network Settings → Manual → SOCKS Host `127.0.0.1` پورت `1080`، SOCKS v5، و تیک «Proxy DNS when using SOCKS v5».

## گزینه‌ها

این گزینه‌ها را می‌توانید جلوی `DualNet.exe` بنویسید، یا به انتهای خط داخل `start.bat` اضافه کنید:

| گزینه | کار |
|---|---|
| `--prefer NAME` | مثل دکمه‌ی «اولویت با این» (بر انتخاب داشبورد غلبه می‌کند) |
| `--speed NAME=16` | مثل دکمه‌ی «سرعت خط» |
| `--limit Wi-Fi=10GB` | سقف مصرف ماهانه برای این کارت |
| `--limit-period day` | سقف روزانه به‌جای ماهانه |
| `--fast` | شروع در حالت «همه با هم» |
| `--weight Ethernet=2` | اگر یک اینترنت سریع‌تر است، اتصال‌های بیشتری به آن بدهید (اینجا دو برابر) |
| `--sticky` | هر سایت ۱۰ دقیقه روی یک اینترنت بماند. برای سایت‌هایی مثل بانک که با عوض شدن IP شما را بیرون می‌اندازند |
| `--exclude NAME` | کارتی که اسمش NAME دارد استفاده نشود (مثلاً VPN) |
| `--only NAME` | فقط از کارت‌هایی با این اسم استفاده شود (قابل تکرار) |
| `--port 1081` | پورت دیگر |
| `--lan` | دستگاه‌های دیگر شبکه (مثلاً گوشی) هم بتوانند از این پراکسی استفاده کنند |

اسم کارت‌ها را در داشبورد یا در پنجره‌ی برنامه می‌بینید (مثلاً `Ethernet` و `Wi-Fi 2`).

## چه چیزی سریع‌تر می‌شود و چه چیزی نه

- ✅ دانلود منیجر چنداتصاله (IDM)، تورنت، مرورگر با چند تب و چند دانلود همزمان: سرعت کل نزدیک به جمع دو اینترنت.
- ❌ یک دانلود تک‌اتصاله، یک ویدیوی یوتیوب، یک تماس تصویری: فقط از یک اینترنت می‌رود. جمع کردن سرعت برای یک اتصال تکی سرور واسط لازم دارد.
- ❌ بازی‌ها و برنامه‌هایی که از پراکسی پشتیبانی نمی‌کنند یا UDP لازم دارند، از DualNet رد نمی‌شوند و مثل قبل از اینترنت پیش‌فرض ویندوز می‌روند.

## نکته‌ها

- اگر VPN روشن است، ترافیکی که از DualNet رد می‌شود مستقیم از LAN و Wi-Fi می‌رود، نه از VPN.
- سایت‌ها ممکن است گاهی IP شما را متفاوت ببینند. اگر جایی از حساب بیرون انداخته شدید، با `--sticky` اجرا کنید.
- برنامه فقط روی `127.0.0.1` گوش می‌دهد، پس از بیرون کامپیوتر قابل دسترسی نیست (مگر با `--lan`).
- رابط کاربری با فونت وزیرمتن است. فونت داخل خود برنامه است و به اینترنت نیاز ندارد (مجوز آن در `src/fonts/OFL.txt`).
